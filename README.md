## 硬件性能测试：CPU 和磁盘 I/O 跑分

说实话，买 DMIT 的人大多是冲着线路去的，但硬件这块也不含糊。

### CPU：AMD EPYC 系列

现役机器分几个平台：洛杉矶部分套餐已升级到 AN5（AMD EPYC 9005 系列），AN4 平台是 AMD EPYC 9004 系列，香港和东京目前多数是 AS3 平台（AMD EPYC 7003 系列）。

用 Geekbench 6 测过洛杉矶 AN4/AN5 平台的机器，单核跑分在 1700 分上下，有的测试出来更高。

这个数字什么概念？普通入门 VPS 用的老 Intel Xeon E5 系列，单核通常在 600–800 分区间。DMIT 的单核性能大约是它们的两倍多，跑个 Docker 容器、起个数据库、搭个代理节点，CPU 绝对不会成为瓶颈。

用 sysbench 压测 CPU（60 秒标准测试），DMIT 机器每秒可以处理 4000 多个事件，响应延迟保持在 0.24ms 左右。拿普通 VPS 的 1.5ms 对比，差距挺明显的，不过对大多数建站场景来说这个差距感知不强，主要影响计算密集型任务。

### 磁盘 I/O：高速 NVMe SSD

用 fio 测混合读写（4k 块大小），读写速度分别能跑到 60MB/s 以上，64k 块大小时读写双双能到 1GB/s 以上。这个成绩说明底层用的是 NVMe，不是普通 SATA SSD。

顺序大文件读写能稳在 1GB/s+ 的区间，MySQL 查询、WordPress 动态页面这类场景，磁盘 I/O 绝对够用。

## 网络性能测试：三网延迟和路由追踪（晚高峰实测）

这才是 DMIT 性能测试的重头戏。特意选了晚高峰（北京时间 21:00–23:00）跑测试，就是要看最难的时候表现怎么样。

### 洛杉矶 Premium（LAX.Pro）：CN2 GIA 三网回程

这是测试过最让人印象深刻的一段数据。

- **上海电信**：平均延迟约 129ms，几乎贴着物理光速极限在跑
- **全国平均**：158ms，东北西部地区延迟基本控制在 180ms 以内
- **丢包率**：0%。晚高峰不丢包，这才是真正值钱的地方

路由追踪确认：电信/联通去程走 163 骨干网，回程进入 CN2 GIA（AS4809，标志性的 59.43 开头 IP 段）。移动去程绕日本 NTT/CMI，但因为回程也切入 GIA 管道，实际体感比很多"直连"的普通移动线路还要快。

**Speedtest 带宽测试（晚高峰）**：套餐标注 1Gbps 的机器，实测下载能跑到 900Mbps+，上传方向在 600–800Mbps 之间。4K 视频随便拖，没有缓冲等待这种事。

### 洛杉矶 Eyeball（LAX.EB）：CMIN2 三网回程

这个系列的路由不太一样：电信联通去程走 CN2/9929，移动走 CMIN2，三网回程都是 CMIN2。

延迟比 Pro 系列高一点，但带宽给的更多——部分套餐带宽能到 4Gbps。联通移动用户用这个比 Pro 更合算，体感不会差太多，价格明显低一档。

### 香港 Premium（HKG.Pro）：延迟王者

香港机房的最大优势是物理距离。实测到国内各大城市延迟普遍在 20–50ms 以内，这是洛杉矶给不了的。

线路：电信走 CN2 GIA 直连，联通走 AS9929/AS10099 精品线路，移动 CMI 直连。三网全优化，延迟数据对于国内用户来说"香得不行"。

唯一要注意：HKG.Pro 价格是三个机房里最贵的，买之前想清楚自己的用户群是不是主要在国内。

### 香港 Tier 1（HKG.T1）：不适合国内用户

一定要单独说一下这个套餐，很多人买错过。HKG.T1 是国际线路，没有国内优化，电信联通可能会绕路去日本甚至美国再回来，延迟反而比美西机器还高。它适合面向东南亚或国际业务的场景，国内用户别搞错了。

### 东京 Premium（TYO.Pro）：亚太低延迟场景

日本机房走电信 CN2 GIA + 联通 AS9929 + 移动 CMI 三路优化。实测上海电信到东京延迟大约在 35ms，移动到东京也在 40–60ms 这个区间，适合游戏服务器、需要日本节点、或者对亚太延迟有高要求的场景。

## 不同场景怎么选

1. **主要用电信宽带、搭代理/梯子**：LAX.Pro 系列，CN2 GIA 回程，电信体验最好

4. **大流量需求、对延迟不极端敏感**：LAX.T1 或 HKG.T1/TYO.T1，超量不断线只降速，流量焦虑直接解决

6. **需要高防建站、怕 DDoS**：LAX.sPro 系列，内置 5Tbps+ 高防，专门为怕被打的建站场景设计
